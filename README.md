# Red River Motorworks

A responsive Next.js website concept for an independent auto repair shop in Austin, Texas.

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000.

## Production build

```bash
npm.cmd run build
```

## Included

- Dark American-premium automotive visual direction with red accents
- Responsive navigation and landing page
- Service cards with estimate selection
- Interactive vehicle / service estimate calculator
- OEM and aftermarket parts preference
- Searchable sample service history
- Appointment request form (front-end demo only)

## Important demo notes

The appointment form currently stores requests only in React state in the browser session. It does not send email or save to a database. Service history entries and business details are sample portfolio content. Connect a backend / CRM and replace placeholder contact information, reviews, certifications, prices, and photos before using this for a real business.

Some photos are loaded from Unsplash and require an internet connection.
